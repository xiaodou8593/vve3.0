# vve:slope_xp

x+朝向斜面

## 生成斜面

```
scoreboard players set x int <x>
scoreboard players set y int <y>
scoreboard players set z int <z>
scoreboard players set w int <w>
scoreboard players set l int <l>
scoreboard players set h int <h>
function vve:slope_xp/_calc_chunk_range
execute as 0-0-0-0-0 run function vve:slope_xp/_calc_nvec
function vve:slope_xp/_model
data modify storage vve:io input set from storage vve:io result
function vve:slope_xp/_new
execute as @e[tag=result,limit=1] run say 1
```

其中xyz,wlh均为10000倍率定点小数

xyz是斜面西北下角坐标，w是斜面宽度，l是斜面长度，h是斜面高度

其中w和l必须为正数，h必须为非负数

生成斜面展示实体(继承上文 @e[tag=result,limit=1])

```
execute as @e[tag=result,limit=1] run function vve:slope_xp/_get
execute as @e[tag=result,limit=1] run function vve:slope_xp/_update_display
```

## 销毁斜面

```
execute as @e[tag=vve_slope_xp] run function vve:slope_xp/_del
```

注意展示实体需要额外销毁

```
execute as @e[tag=vve_slope_display] run function vve:slope_display/_del
```

## 在介质探测函数中探测斜面

向_detect_*函数中插入以下代码

```
# 获取区块坐标
scoreboard players operation chunk_x int = c_x int
scoreboard players operation chunk_z int = c_z int
scoreboard players operation chunk_x int /= 10000 int
scoreboard players operation chunk_z int /= 10000 int
scoreboard players operation chunk_x int /= 16 int
scoreboard players operation chunk_z int /= 16 int
# 区块查询
execute as @e[x=0,y=8,z=0,distance=..1,predicate=vve:match_chunk] run function vve:call_material
execute if score material_response int matches 1.. run return fail
```
